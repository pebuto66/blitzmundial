## 🇬🇧 English

**Blitz Mundial** (*World Domination*) is a turn-based strategy game, inspired by Risk, for **2 to 6 players on a single screen**. Play locally with friends by passing the device, add AI bots to fill empty seats, or challenge others online.

### 🎯 Features

- **Local hot-seat play** for 2–6 players (mix of humans and bots)
- **Online multiplayer** mode
- **Save/Load** games to continue later
- Classic Risk-style mechanics plus new tactical units:
  - 🪖 **Armies** — your core forces on the board
  - 🗼 **Towers** — defensive structures
  - ✈️ **Planes** — strike any territory you've scouted; cost **50 L** per territory traveled (round trip), single use
  - 🛡️ **Tanks** — cost **25 L** per attacked territory and add **+2** combat power
  - 🛫 **Airports** — grant **+1 reserve plane** per turn and give your planes **global range**; also act as **anti-air shields** against enemy planes
  - ☢️ **Missile Silos** — allow you to launch a **nuclear missile**, destroying all towers in the impact zone

### ⚔️ Core Rule

Only **one attack target per turn** — you may strike the same territory multiple times, but not switch targets mid-turn.

### 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>

# Install dependencies
npm install

# Start the dev server
npm run dev
```

> Requires [Node.js](https://nodejs.org/) and npm installed.

### 🧰 Tech Stack

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS

### 📖 How to Play

1. Choose the number of players (3–6) and set each as Human 👤 or Bot 🤖.
2. Each player receives their starting materials.
3. On your turn, deploy units, choose **one** territory to attack, and use planes, tanks, airports, or a missile if available.
4. Eliminate your opponents or dominate the board to win.

## 🇪🇸 Español

**Blitz Mundial** es un juego de estrategia por turnos, inspirado en Risk, para **2 a 6 jugadores en una sola pantalla**. Jugá en local pasando el dispositivo entre amigos, sumá bots para completar los cupos, o desafiá a otros en modo online.

### 🎯 Características

- **Modo local (hot-seat)** para 2–6 jugadores (combinando humanos y bots)
- **Modo multijugador online**
- **Guardar/Cargar** partidas para continuar más tarde
- Mecánicas clásicas al estilo Risk, más unidades tácticas nuevas:
  - 🪖 **Ejércitos** — tus fuerzas principales en el tablero
  - 🗼 **Torres** — estructuras defensivas
  - ✈️ **Aviones** — atacan cualquier territorio explorado; cuestan **50 L** por territorio recorrido (ida y vuelta), uso único
  - 🛡️ **Tanques** — cuestan **25 L** por territorio atacado y suman **+2** en combate
  - 🛫 **Aeropuertos** — otorgan **+1 avión de reserva** por turno y dan **alcance global** a tus aviones; también actúan como **escudo antiaéreo** contra aviones enemigos
  - ☢️ **Silos de misiles** — permiten lanzar un **misil nuclear**, que destruye todas las torres en la zona de impacto

### ⚔️ Regla Principal

Solo se permite **un objetivo de ataque por turno** — podés atacar el mismo territorio varias veces, pero no cambiar de objetivo dentro del mismo turno.
